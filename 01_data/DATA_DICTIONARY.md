# Data dictionary

All files are **synthetic** (generated by [`scripts/generate_data.py`](../scripts/generate_data.py)). Godavari Finance is a fictional lender. Period: 1 January to 30 June 2026.

## loan_applications_raw.csv (15,250 rows) and loan_applications_clean.csv (15,000 rows)

One row per personal-loan application. The raw file has deliberate data-quality issues for the cleaning step:

| Issue | Rows |
| --- | --- |
| Exact duplicate rows | 250 |
| `channel` in wrong case or with extra spaces (dsa, MOBILE APP, ' Branch ') | 555 |
| `loan_amount` stored as text with ₹ and commas (₹3,50,000 style) | 400 |
| Blank `employment_type` | 200 |

In the clean file: duplicates removed, `channel` standardised, `loan_amount` numeric, blank `employment_type` set to `Unknown`.

| Column | Meaning |
| --- | --- |
| application_id | Unique ID (SS00001 ...) |
| submitted_at | Date and time the application was submitted |
| submit_day | Day of week of submission (Mon ... Sun) |
| channel | Mobile App / Website / Branch / DSA |
| branch_city | City of the servicing branch (10 cities) |
| city_tier | Tier 1 / Tier 2 / Tier 3 |
| employment_type | Salaried / Self-employed / Unknown |
| cibil_band | 750+ / 700-749 / 650-699 / Below 650 |
| loan_amount | Loan amount applied for, in rupees |
| last_stage_no | Last stage reached (2-6) |
| last_stage_name | Name of that stage |
| final_status | Disbursed / Rejected / Withdrawn |
| close_reason | Why the application closed without a loan (blank if disbursed) |
| doc_rerequests | Number of times documents were sent back for re-upload (0-2) |
| tat_hours | Hours from submission to disbursal (Disbursed only, else blank) |

## stage_events.csv (67,346 rows)

One row per attempt at a stage. Document Verification can have up to 3 attempts.

| Column | Meaning |
| --- | --- |
| event_id | Unique ID (EV000001 ...) |
| application_id | Links to loan_applications.application_id |
| stage_no / stage_name | 2 Document Verification · 3 Credit Bureau Check · 4 Underwriting · 5 Sanction & Customer Acceptance · 6 Disbursal |
| attempt_no | 1, 2 or 3 |
| start_time / end_time | When the attempt started and ended |
| outcome | Passed / Re-requested / Rejected / Withdrawn |
| issue | Re-request reason or close reason |
| duration_hours | end_time minus start_time, in hours |

## Rules used to generate the data

- Ops staff work Monday to Saturday, 10:00-18:00, so staff work pauses at night and on Sunday. Customer actions (re-upload, e-sign) can happen any time.
- Re-request chance depends on channel (highest for DSA) and employment type (higher for self-employed).
- Rejection depends on CIBIL band and employment type.
- At the sanction stage, the chance a customer withdraws rises with how long they have already waited.
